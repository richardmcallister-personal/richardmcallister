How they’re built

Every site is plain pages on Cloudflare Workers, deployed from GitHub on every push. Live data goes through each site’s own Worker and is cached there, so API keys never reach the browser. All of it was built with Claude Code.

SiteData fromThe hard part
manutd.wikiAPI-Football, Wikipedia, Wikimedia Commons, tickets.manutd.comAPI-Football’s free plan has no current-season data, so live results needed the paid plan.
CelticWikipedia, API-FootballDeciding how to count Rangers across 2012: one club, with an asterisk on everything since.
limerickhurling.wikiWikipediaHurling scores are goals and points, so every result is kept as 2-15 and as its total, 21, for wins and margins to add up.
irelandfootball.wikiWikipedia, API-FootballJoining a century of Wikipedia results to the live feed. Games from before the feed are found by date instead.
irelandrugby.wikiHighlightly Rugby API, WikipediaThe free plan allows 100 calls a day and lists no future URC or European fixtures, so those are kept by hand.
bobdylan.appsetlist.fm, Wikipediasetlist.fm allows about two requests a second, so 4164 shows take a slow, polite crawl.
ledzeppelin.appsetlist.fm58 of the 536 shows have no setlist on record.
Billy Connollybillyconnolly.com tour pages via the Internet Archive, WikipediaThe official tour pages are gone, so dates come from archived copies: 259 shows across 53 tours, with many early ones undated.
