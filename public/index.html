How they're built

Same pattern for every site: small, cheap to run, and deploys itself on every push.

LayerChoiceWhy
PagesStatic HTML and HugoLoads instantly, nothing to patch
HostingCloudflare WorkersGlobal edge, custom domains, free tier covers it
Live dataWorker proxy with KV cacheAPI keys stay server-side; one fetch serves everyone
SourcesSports data APIs, WikipediaFixtures and results live; history built into JSON
DeploysGitHub → Workers BuildsPush to main and it's live in about a minute
DesignOne system, per-site colourGrey ground, white cards, light and dark
